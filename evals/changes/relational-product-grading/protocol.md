It verifies the exact private proof digest and captured primary input against the pre-reviewed request hash, rebuilds the ordinary request, and decodes the unchanged provider output using the ordinary strict role-slot decoder. It compares the served R14 report to the current grader and scoring output. A pinned pre-change grader from Git commit `4f99ef4` supplies the before/after supporting-attribute comparison; its source hash is checked before use.

It also requires the features attribute to change from not measured to measured 1, and both full reports to remain incomplete with null score. Evidence comparisons remove generated IDs and observation timestamps and publish only hashes, never source excerpts or the captured model output. The reviewer must independently verify the actual source and citations in the private proof.
