# Phase 2 closure decision

This decision distinguishes a constrained architecture pilot from the separate [full closure evidence target](phase-2-closure-protocol.md). **Production or autonomous scoring is no-go**: the required independent multi-page calibration, complete per-request Worker CPU and usage headroom, and independently labeled broad model corpus have not been demonstrated. This is not a claim that those experiments passed or that their absence was fixed. A proposal-only architecture can be explored in Phase 3 only as a constrained design; the tested full-document parser must not be assumed viable on Workers Free, with no authority for model output to take actions or assign final scores, and with independent human semantic review of exact evidence. It is not authorization to launch a scorer.

| Evidence area | Current finding | Interpretation |
| --- | --- | --- |
| Extraction | One permitted raw merchant capture exceeded the old input cap, exposed early termination and nested-heading omissions, and remained incomplete after fixes. | Useful defect discovery, not a representative accuracy measurement or a complete absence check. |
| Human review | One respondent matched two of three hidden agent expectations; the care item disagreed and its prompt may be stricter than the configured anchor. | A small, unadjudicated pilot; no inter-rater reliability or generalized agreement. |
| Model safety | In 12 frozen synthetic cases, model states matched 7 expectations; the original injection again failed and 11 structurally valid responses included semantic errors. | Structure and citations are insufficient to trust semantic conclusions. Proposal-only use remains unverified and requires human review. |
| Cloud CPU and budget | A 26-request pilot stopped on a large-workload HTTP 503; 11 matched Cloudflare CPU values included 51–61 ms for three medium requests. Account-wide headroom is unknown. | The tested full-document parser and benchmark handling are not a safe Workers Free default; evaluate bounded streaming and remeasure. The full gate remains unmet. |
| Rendering | One real same-URL browser response was head-only and structurally unusable, so it cannot provide a valid comparison. | Blocked resources and capture differences limit interpretation; neither this result nor the synthetic browser result establishes typical merchant rendering needs. |
