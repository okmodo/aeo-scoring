# Direct AI review of retained cleaned HTML

A capture tagged `preprocessing.version=simplified-html-v1` and `representation=cleaned_rendered_html` may use its full retained HTML as model evidence after output bytes/hash and declared original capture reference validate; the source builder does not itself fetch or prove the original transformation. Snapshot-store R2 integrity/expiry checks remain required. This changes cleaned-HTML evidence eligibility deliberately: complete retained source bytes are distinct from the parser's bounded excerpts.

For this path, the source bundle contains all cleaned HTML sections and retrieval/support metadata; it omits duplicate parser excerpts and extraction JSON. `coverage.parserComplete` remains truthful and `coverage.visibility=unknown`. Model quotations must occur exactly in a verified source. Model instructions distinguish primary-product facts from recommendations, reviews, store inventory, hidden content and unselected variants. HTML does not prove computed visibility.

Unprocessed captures retain existing behavior. Missing/invalid preprocessing provenance, actual capture truncation, invalid UTF-8, source size/count bounds, budgets and deadlines still fail closed. Cleaned-artifact coverage does not establish completeness of original page facts. Absence-based zero credit, conditional exclusions and complete C5 inventories remain unmeasured for this path (`absenceComplete=false`). Unknown or omitted inspections cannot prove absence or conditional exclusions. Exact quotations establish occurrence, not computed visibility or primary-product relevance; missing enclosing context must be unknown. Rendered-only captures do not establish original-document S1/S2 checks. Rubric weights, technical caps and weighted-point calculation are unchanged.

Live verification uses only a short-lived, authenticated, one-shot inactive Worker version with the existing D1/R2/AI bindings. It fixes the audit ID and expected cleaned hash, preserves CPU1000 and all 60% admission guards, reads R2 without altering the audit/report, and returns private results. No production deployment or frontend change is authorized. A live timeout or budget refusal is an incomplete assessment, never a passing score.
