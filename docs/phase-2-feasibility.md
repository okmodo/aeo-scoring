# Phase 2 feasibility prototype

Decision: **not yet ready for a production scorer or a free-tier feasibility commitment**. The offline prototype demonstrates bounded extraction on small synthetic inputs. Two live synthetic model judgments yielded one correct result and one prompt-injection failure; a single synthetic browser render succeeded. See the [live experiment](cloudflare-live-experiment.md). Real-page extraction accuracy, representative raw/rendered differences, human scoring agreement, Cloudflare CPU and end-to-end budget remain unmeasured. See [calibration observations](../evals/fixtures/feasibility/calibration/observations.md) and [Cloudflare limits and experiment](cloudflare-feasibility.md).

Run `npm run test:feasibility`. `scripts/feasibility.mjs` accepts caller-supplied HTML and records source URL, raw/rendered label, observation time and offsets into that snapshot. It does not fetch or execute pages. It emits bounded text plus inline JSON-LD Product name/description and Offer price/currency, and direct text in visible h1 or itemprop description/price/currency. Observations retain their origins and are not reconciled into truth. Conflicting values remain visible; multiple products, variants, linked offers and currencies require contextual judgment. JSON-LD evidence offsets cover the entire script, not individual properties. It does not validate schema or fetch remote JSON-LD contexts. Invalid or unsupported markup is unmeasured, never evidence of absence. It does not measure C1–C5 or S1–S8 and emits no score.

Extraction is restricted to 1 MiB (increased for the permitted 815,720-byte pilot input; cloud runtime feasibility remains unproven), 30,000 visited nodes, 100 text findings and 100 fields; individual text/field values are bounded. Truncation marks coverage incomplete. Parser input size is bounded, but the parser constructs a tree before the node limit is applied. Hidden detection is deliberately incomplete: it handles common attributes and inline styles, not stylesheets, inherited CSS, JavaScript, shadow DOM or visual layout. The raw/rendered pair is an invented fixture supplied to the same parser, not a browser experiment. A phrase found in text, including a negation, is only a lexical match; an unobserved phrase never establishes absence.

The content request builder and validator are **offline contract experiments**, not a Cloudflare API client or a claim of model safety. A byte limit is not a verified token limit. IDs show only that a model response references supplied excerpts; they do not prove that an excerpt entails its conclusion. Invalid fields, invented IDs, unsupported values and ungrounded substantive responses fail closed. Prompt injection can still influence a model: input and output remain untrusted and have no authority to call tools, change settings, invent facts or trigger actions. Semantic review is necessary. A model judgment is not an independently measured human score.

A future network service must independently enforce HTTP(S)-only public destinations; resolve and pin permitted public IPs at connection time, reject private, loopback, link-local, reserved and IPv4-mapped destinations, and repeat validation on every bounded redirect to prevent DNS rebinding and SSRF. Limit response bytes, decompression, total time and redirects; validate type/status; do not forward credentials or access internal resources. Respect applicable site access policies. Rendering requires isolated browsers without internal network access, with navigation, subresource, download and execution budgets. These controls are requirements for future work, not implemented by this offline prototype.

## Local measurement

On 2026-11-05, `node scripts/feasibility-benchmark.mjs` on macOS arm64 Apple M4, Node v25.9.0: 100 warmups and 1,000 inspections of four 26–177 byte synthetic pages yielded median/p95/max elapsed 0.010/0.029/0.334 ms and process CPU 0.010/0.130/1.571 ms. This tiny, warm local run is not representative of full pages, rendering, network, cold starts or Cloudflare's accounting; Node 25 also differs from the project's Node 24 CI runtime. Repeat the command for a new observation, not a fixed threshold.

The synthetic expected outcomes were written independently as fixture assertions and are not representative accuracy estimates. Three indexed-source examples provide limited rubric anchors, not extractor inputs or ground truth; robots checks did not establish permission to fetch those pages. Before advancing, obtain permitted representative raw/rendered snapshots, independent human labels, reliable agreement measures, and bounded live Cloudflare CPU/browser/model measurements on an account confirmed free. Establish a go/no-go against actual workloads and quota contention; discuss scope if limits cannot support it.
