# Hosted sample preview deployment

This is a manual, post-review deployment of static sample data. It does not crawl sites or perform production scoring. CI must never deploy. Use only the Free plan, a newly created Pages Direct Upload project, and its `pages.dev` hostname. Do not change existing Workers, Pages projects, DNS, routes, domains, account subdomain, billing, secrets, or other Cloudflare services.

Before any Cloudflare write, hosted CI and independent review must pass for the exact source commit. Verify the intended account and Free plan. List all Pages projects, Workers, Worker domains, zone routes, and the account Workers subdomain and retain a private sanitized before snapshot. The candidate project `aeo-scoring-preview-20261105-kk7` was absent when checked; immediately recheck it and stop if it exists. Never use or update a project created by someone else. A 404 for the account Workers subdomain is expected; do not create it or open the Workers & Pages landing page, which Cloudflare says can create it automatically.

Build the reviewed commit locally, verify the generated files and record the commit and SHA-256 of every asset. Verify fewer than 20,000 files, each at most 25 MiB. Then, with explicit deployment authorization, the Cloudflare connector can create only the new project:

1. `POST /accounts/{account_id}/pages/projects` with JSON `{ "name": "aeo-scoring-preview-20261105-kk7", "production_branch": "main" }`. Stop if the API returns a collision or any unexpected response. Keep the creation response and project ID privately. Do not create a Git integration or other bindings.
2. Obtain a short-lived upload token using `GET /accounts/{account_id}/pages/projects/{name}/upload-token`. Treat it as a secret. Feed it to `node scripts/pages-upload-assets.mjs dist /private/tmp/aeo-preview-manifest.json` on standard input; never put it in a command line, commit, or persistent log. The helper only uploads assets with that token; it does not create a project or deployment. The helper requires network access to Cloudflare's API. Its SHA-256-based content keys and API flow successfully uploaded four assets for the initial deployment; stop on any unexpected failure.
3. Using the connector and the creation response to confirm ownership, `POST /accounts/{account_id}/pages/projects/{name}/deployments` as multipart form data. Include `manifest` as a string using `form.append("manifest", JSON.stringify(manifest))`, `branch` as `main`, `commit_hash` as the reviewed commit, and `commit_dirty` as `false`. Do not send the manifest as an `application/json` Blob: the initial attempt returned HTTP 400, code 8000096 (expected manifest); the string form succeeded. Do not include `_worker.js`, functions, or bindings. This call deploys publicly; only proceed if the source and assets match the reviewed build. The expected hostname is `https://aeo-scoring-preview-20261105-kk7.pages.dev`; use the returned hostname and deployment URL as authoritative.
4. Wait for success and test the live URL, including sample-data disclosure and basic navigation. Repeat the read-only inventory and compare the existing-resource snapshot, accounting only for the newly created Pages project and deployment. Record actual commit, asset hashes, project and deployment IDs, URLs, verification results, and any discrepancy in a private sanitized provenance record. Do not record tokens. Stop and report any unexpected account change.

The Pages API documents [project creation](https://developers.cloudflare.com/api/resources/pages/subresources/projects/methods/create/), [asset upload](https://developers.cloudflare.com/api/resources/pages/subresources/assets/methods/upload/), and [deployment creation](https://developers.cloudflare.com/api/resources/pages/subresources/projects/subresources/deployments/methods/create/). Cloudflare documents [Direct Upload](https://developers.cloudflare.com/pages/get-started/direct-upload/) and [Pages limits](https://developers.cloudflare.com/pages/platform/limits/). Static Pages requests are free; confirm current limits before deployment.
