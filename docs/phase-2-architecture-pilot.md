# Bounded architecture pilot protocol

Frozen before this pilot's outcomes. The separate closure protocol remains unchanged as the evidence target for launch and autonomy. This pilot informs a constrained Phase 3 architecture decision; it does not establish merchant accuracy, operational scalability, or autonomous model safety.

Use the already independently captured, robots-permitted raw product page and at most one permitted browser render of the same URL, without bypassing challenges. Retain retrieval status, times, hashes, and three blind human judgments over the same matched excerpts; a single rater and a single page cannot establish agreement or representative accuracy. Respect copyright: retain only short excerpts, hashes and source metadata in the repository. Report unknowns and mismatched or missing raw/rendered captures rather than synthesizing a pair. A 1 MiB parser input ceiling permits the 815,720-byte raw capture; the entire tree is still parsed before node limits, so the ceiling does not establish runtime safety and must be CPU-tested.

After independent review and owner authorization only, run no more than 30 total Worker requests across three fixed synthetic size classes and error checks in a new isolated protected Pages benchmark, with no arbitrary input, crawling, or cloud calls in CI. Record exact request count, actual Worker-reported CPU per request, errors and account quota/usage where available. Within this small sample, report observed values and maxima rather than claiming reliable p95. No claim of full-protocol passage follows. The benchmark must have enforceable access and a strict expiry/request bound; do not deploy if those cannot be demonstrated. Never alter pre-existing resources or enable a Workers subdomain.

After review and a separately authorized free budget, make at most 12 total model calls to frozen synthetic cases including the original injection, clean assertions, negation, conflicting evidence and diverse instruction attacks. Record all outputs, errors, usage and any retries within the cap. These are untrusted proposals with zero authority to take actions or produce a final score; independent human semantic review of exact evidence remains mandatory. Zero observed errors in this small pilot is not proof of safety. No model response is accepted as a human label.

A constrained architecture may proceed to design only if the reviewed proposal boundary has no execution or score authority, the measurements and failures are disclosed, and the owner accepts unresolved workload and calibration limits. Any CPU exceedance, unavailable usage evidence, injection success or missing human judgment must remain visible and constrain design; do not claim full phase-2 launch readiness. The full closure protocol remains the stricter gate for production scoring and autonomy.
