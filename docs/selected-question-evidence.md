# Selected values in question evidence

The content-facts candidate and decoder checks treat a selected size, color, or configuration as product-choice evidence. That choice alone does not answer a category decision question about use, fit, compatibility, limitations, or selection. The source observation remains available for configuration and attribute extraction, and the independent broad cues used to prevent unsupported absence conclusions are unchanged.

For a mixed observation, the question role remains eligible only when that observation also contains evidence relevant to the particular question: for example, a fit or width description, a body measurement, an audience or use, a limitation cue, or actionable selection guidance. The same role checks apply when decoding a proposed fact; a proposal outside eligibility remains unknown. These checks are conservative source filters, not a guarantee that every eligible proposal is semantically supported. Independent review still examines raw model roles and deterministic supplements separately.

The R13 result remains closed and failed. This change does not alter its recorded request, output, or outcome. A subsequent validation must use its own frozen source, request, and independently reviewed evidence.
