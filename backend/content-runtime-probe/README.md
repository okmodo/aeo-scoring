# Isolated Workers Free runtime experiment (review before deployment)

This is a separately configured experiment, not a production service. Five fixed synthetic cases exercise production-shaped streaming retrieval, native extraction, category selection, `buildContentFactsRequest`, `decodeContentFacts` and `scoreAudit({validatedFacts})`. The complete shirt supplies the frozen 31-fact response, not model-generated judgments; partial uses empty facts; hostile instructions must be rejected; ~372 KiB comments exercise a large body; the over-1 MiB case must reach the actual retrieval stream limit and report incomplete coverage. Fake egress supplies those synthetic cases. Local tests do not measure Cloudflare CPU.

The authenticated `/sync/kokatat` route is fixed to `https://kokatat.com/naiad-pfd-lvhnai`. It uses actual `retrieve` and strictly public egress, with the production 8-second bound and optional robots, sitemap, guides and policy inspection. Redirects and optional evidence are handled by the production retrieval restrictions. It returns the bounded prepared observations and fact request to the authenticated caller, with source URL queries removed and no raw HTML or script/JSON-LD payload. These excerpts are still merchant content: use `capture-public.mjs` and keep the result in a protected temporary file, never in logs, version control, or a public artifact. `PROBE_PRIVATE_OUTPUT` must be a new `/private/tmp/aeo-*.json` file; the script creates it mode 0600. A second merchant is not configured. This route prepares facts but does not run inference or produce a complete model-assisted report. No model, database, production service or binding is used.

The Worker accepts only fixed paths and ignores request bodies; caller-selected URLs and inference are unavailable. A random secret and timestamped HMAC in headers authenticate requests; signatures can be replayed during their 60-second window. Set an absolute expiry within one hour. The expiry fails closed but is not automatic deletion or a global request cap; delete the Worker promptly afterward. Do not use it for untrusted public traffic or reuse its secret. The invocations log only case paths, and background completion logs only synthetic summaries. Scrutinize platform trace fields before exporting; never include request authorization headers.

Before deployment, independently review the exact bundle, limits, logging and cleanup; confirm the dedicated `aeo-content-runtime-probe-20261109-kk7` name in the separate config is still absent from the account inventory. Run `node backend/content-runtime-probe/local-test.mjs` using the project-local dependencies. Prepare a protected temporary secrets JSON containing `PROBE_SECRET` (at least 32 random characters) and `PROBE_EXPIRES_AT` (absolute Unix milliseconds, no more than one hour away). Use the existing Cloudflare `cf` workflow with this isolated config and `--provision=false`; do not touch existing project Workers or resources. Confirm the deployed name and expiry; remove the secret file. No operation here authorizes production deployment.

Run `run.mjs` with `PROBE_ORIGIN` and `PROBE_SECRET` in a protected environment. It makes 10 calls: five synchronous and five background. The separate real-page capture requires `PROBE_PRIVATE_OUTPUT` and makes one additional call. Run `node hashes.mjs` to record synthetic input, support and reference-response source hashes. Record the exact revision, timestamps, response status, ray IDs, result summaries, CPU, wall time, outcomes and cleanup. Do not put secrets in shell history. Background `202` means accepted; require its corresponding `completed` log. A fast completed task does not prove operation near the 30-second lifecycle limit. The live route and synthetic tests do not test a model call, database persistence or an entire audit invocation, and cannot prove a complete report fits the Free budget.

For actual CPU, query Workers Logs, scoped to this Worker and run interval, at 100% invocation sampling. `metrics.mjs` implements an ad-hoc Observability API query: set `CF_ACCOUNT_ID`, `CF_API_TOKEN`, `PROBE_NAME` and `PROBE_FROM_MS` (13-digit UTC epoch milliseconds), then run `node backend/content-runtime-probe/metrics.mjs`. The endpoint documents **Workers Observability Write** permission even for temporary query execution. The documented `invocations` response groups events by request ID and contains `$workers.cpuTimeMs`, `wallTimeMs` and `outcome` on invocation events. Verify query completion, schema, correlation and pagination against dashboard logs before relying on this untested script. Missing telemetry, permission failure, failed invocations, `exceededCpu`, or missing background completion means feasibility is unknown. GraphQL `workersInvocationsAdaptive` quantiles are aggregates, not individual CPU readings; local elapsed or connector wall time is not CPU. Compare every measured CPU value with 10 ms and report all overruns; Cloudflare allows occasional enforcement flexibility, so success alone is insufficient.

Delete only the new probe after measurement, verify absence through a fresh inventory, and record deletion/expiry, actual usage and gaps. Zero AI calls means zero probe neurons; any later inference experiment needs a separately reviewed implementation and reservation ledger capped at 8,000 neurons per UTC day across this project, with no paid fallback.
