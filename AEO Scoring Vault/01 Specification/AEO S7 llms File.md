# AEO S7 llms File

S7 allocates 1 point and is labeled emerging practice.

| Subcheck | Points |
|---|---:|
| Retrievable meaningful llms.txt identifying site and purpose | 0.5 |
| Useful working catalog and policy or help links | 0.5 |

Incomplete but useful content earns half of the affected subcheck. Empty templates, unrelated text, and HTML error pages receive zero. Record the proposal version used for evaluation. Useful content in another agent file does not automatically substitute for llms.txt.

This criterion is our low-weight readiness choice, not a claim that all major engines read the file or require it. A generated file earns no points until the merchant publishes it and a subsequent audit observes it.
