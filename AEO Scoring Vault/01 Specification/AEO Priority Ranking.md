# AEO Priority Ranking

Rank fix groups as follows:

1. Confirmed access or eligibility restrictions, identifying affected systems and possible intentional policy.
2. Established-practice actions with calculable recovery, highest incremental points first.
3. Findings requiring investigation or a decision before recovery can be calculated.
4. Emerging practices, including llms.txt and website agent guides.

Within equal-point actions, prefer higher evidence/outcome confidence, fewer dependencies, then lower effort only when defensibly estimated. Use stable criterion order as the final tie-breaker. Do not invent an opaque combined priority number.

Incremental recovery is relative to earlier actions in the displayed plan. Overlapping fixes must not repeatedly claim the same benefit; merge, show alternatives, or expose shared recovery. Users may filter by owner. A Quick wins view is optional and must not bury access restrictions.

An access warning can be more consequential than its two-point scoring allocation suggests. Keep it prominent without adding another numerical penalty.
