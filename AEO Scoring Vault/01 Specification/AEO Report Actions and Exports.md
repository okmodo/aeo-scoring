# AEO Report Actions and Exports

Offer a downloadable human-readable report and versioned structured JSON. The JSON is a future integration boundary for data-improvement services; API and schema details remain implementation design work.

Provide optional generation of llms.txt and website agent guidance, labeled emerging practice. Output files and publishing instructions; never write to the merchant's site. Generated content must be source-grounded and respect the same no-fabrication rule.

Allow another audit and explain cache reuse. Retain the actual audit time and versions. Re-audits should distinguish observed score changes from hypothetical recoverable points.

Unlisted/noindex public report links are a proposed default from the handoff, not a confirmed privacy boundary. Final result visibility, retention, export format, share behavior, and refresh controls remain open decisions.
