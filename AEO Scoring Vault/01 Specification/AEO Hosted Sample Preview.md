# AEO Hosted Sample Preview

The preview demonstrates the report with a fictional running shoe scoring 84.5/100: Structure 36.5/40 and Content 48/60. Entered URLs are not fetched or assessed, and all findings are synthetic. It is not a production assessment.

The intended host is a new isolated Cloudflare Pages project on the Free plan, after hosted CI and independent review. Existing Cloudflare services and configurations must remain untouched. The preview does not resolve Phase 2 extraction, calibration, model reliability, or Cloudflare feasibility gaps.
